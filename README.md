# AI Native Obsidian Knowledge Base

这是一个以长期知识积累、AI Agent 协作、Research 收集、知识图谱和内容创作为目标的 Obsidian Vault。

## 目录架构

| 目录 | 用途 |
| --- | --- |
| `00_收件箱_Inbox` | 所有新资料的入口，先收集再处理 |
| `01_项目_Projects` | 原有项目、学习和创作资料 |
| `02_领域_Areas` | 长期维护的领域知识，目前包含展览设计、通用能力、通识和生活领域 |
| `03_资源_Resources` | 读书、行业文章、原子知识卡片、课程和 MOC |
| `04_归档_Archive` | 已完成、过时或废弃内容 |
| `06-Projects` | AI Agent 使用的项目索引、状态、决策和下一步 |
| `90_模板_Templates` | 笔记模板 |
| `97-AI-Memory` | 稳定的长期记忆，不保存聊天记录 |
| `98-AI-Context` | 当前目标、研究任务、工作状态和未决问题 |
| `99_附件_Assets` | 图片、PDF、图纸、表格、音视频等附件 |
